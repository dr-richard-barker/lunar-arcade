▲ LUNAR HABITAT · BALANCE HARNESS

Scenario runner

Runs the real simulation headlessly and asserts on the result. Loads config / grid / sim / autopilot / league only — no canvas, no input, no autosave, and no localStorage write, so running this cannot touch a saved colony or the league table. Nothing here re-implements game logic: expectations are read from LH.C, LH.MOD and LH.TIERS, so a config change reshapes the tests instead of silently invalidating them. The event RNG is seeded, so runs are repeatable.
